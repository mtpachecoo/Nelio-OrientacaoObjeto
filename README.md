
# C# Programação Orientada a Objetos

Este repositório contém a fundação da minha jornada como desenvolvedor .NET, consolidando os módulos iniciais do curso de C# Programação Orientada a Objetos do Prof. Nélio Alves.

## Status
- Concluído e Arquivado ✅ Os estudos avançados de Arquitetura, APIs e Projetos Reais foram movidos para o repositório [Project-Order-System](https://github.com/mtpachecoo/Project-Order-System).

## Aprendizados

Registrar o domínio da sintaxe básica, lógica de programação e os primeiros pilares da Orientação a Objetos. Este código serve como base de consulta para algoritmos e estruturas fundamentais.


##  Tecnologias e Conceitos Dominados

- Fundamentos: Variáveis, tipos básicos, entrada/saída de dados e estruturas condicionais/repetitivas.

- POO Básica: Classes, atributos, métodos, construtores e encapsulamento.


- Gestão de Memória: Structs, classes (Stack vs Heap), Garbage Collector e listas.


- Versionamento: Commits semânticos e organização de branches.
